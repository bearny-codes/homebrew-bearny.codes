# BearnyTerm Homebrew Tap

Homebrew Cask for [BearnyTerm](https://github.com/bearny-codes/homebrew-bearny.codes/releases).

## Install

```sh
brew tap bearny-codes/bearny.codes
brew trust --cask bearny-codes/bearny.codes/bearnyterm
brew install --cask bearnyterm
```

The current build is Developer ID-signed and notarized by Apple.

Requires macOS 15 or later.
